# d2-mcp 2.0.0

Published on October 20, 2026. [Release and downloads](https://github.com/h0rv/d2-mcp/releases/tag/2.0.0)
and [changes since 1.2.0](https://github.com/h0rv/d2-mcp/compare/1.2.0...2.0.0).

- **Renderer:** D2 0.9.0 with bundled Dagre, ELK and open-source TALA, native PNG,
  explicit rendering options, board selection and opt-in local/inline assets.
- **MCP:** official Go SDK 1.8.0, stateless Streamable HTTP, structured diagnostics
  and artifact metadata, with stdio and legacy SSE retained.
- **Files and limits:** explicit input/output roots, controlled file replacement,
  frozen imports and bounded source, asset and rendering work.
- **Optional integrations:** the embedded MCP Apps viewer (`--ui`), static
  Claude/Codex/Pi skills and prompts, and a Cloudflare Wasm deployment target with
  a setup page, explicit public/private access and public request limits.
- **Distribution:** five platform binaries with `SHA256SUMS`; CI exercises native
  installations, rendering, transports, the viewer and the Cloudflare target.

[Install 2.0.0](../installation.md) and read the
[migration notes](../compatibility.md#upgrading-from-120-to-200) before upgrading
from 1.2.0. Source builds require Go 1.27.2+. The default binary still exposes
three core tools, keeps no documents or HTTP sessions, and leaves the viewer off.
The document-store interface is for custom integrations; no backend is bundled.

The supported D2 subset and resource limits still apply. The known upstream
[Dagre ASCII arrowhead defect](../ascii-rendering.md) remains; explicit ELK is a
workaround for the reproduced diagram.
