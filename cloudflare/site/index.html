Connect your agent

Use the public Streamable HTTP endpoint. No install or token needed.

https://d2.horv.co/mcp

Claude Code

claude mcp add --scope user --transport http d2 https://d2.horv.co/mcp

Codex

codex mcp add d2 --url https://d2.horv.co/mcp

Pi

pi mcp add d2 --exposure direct --url https://d2.horv.co/mcp

Then ask: “Draw a diagram of a client talking to an API and a database.”

Send complete source on each call. The hosted service has no file access or saved diagram library. Public use shares a request allowance. More client setup.

Use it locally

Install the current source with Go 1.27.2+:

go install github.com/h0rv/d2-mcp@main
d2-mcp --version

Put Go’s bin directory on your PATH. PNG rendering is built in; no browser or separate D2 executable is needed.

Connect the local server, for example with Claude Code:

claude mcp add --scope user --transport stdio d2 -- d2-mcp --transport stdio

Choose local or remote setup to avoid registering d2 twice.
